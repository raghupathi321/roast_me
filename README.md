
  <h1> Roast Generator API</h1>
  <p>
    This project is a <strong>Flask-based web API</strong> that humorously roasts users by combining:
  </p>
  <ul>
    <li>Custom roasts from a text file (<code>roasts.txt</code>)</li>
    <li>Scraped <strong>TryHackMe user profile data</strong> (points, skills, badges)</li>
    <li>AI-generated content using <strong>Gemini API</strong></li>
  </ul>

  <hr>

  <h2>Features</h2>
  <ul>
    <li>Scrapes TryHackMe profile for <strong>points, badges, and skills</strong>.</li>
    <li>Fetches a random roast from a <code>roasts.txt</code> file.</li>
    <li>Generates AI-powered roasts using <strong>Google Gemini API</strong>.</li>
    <li>Provides an easy-to-use <strong>REST API endpoint</strong>.</li>
    <li>Supports <strong>CORS</strong> for frontend integration (e.g., React.js).</li>
  </ul>

  <hr>

  <h2> Tech Stack</h2>
  <ul>
    <li>Python 3.x</li>
    <li>Flask (Backend API)</li>
    <li>Flask-CORS</li>
    <li>Requests + BeautifulSoup (Web scraping)</li>
    <li>Google Gemini API (AI roast generation)</li>
  </ul>

  <hr>

  <h2>🚀 API Endpoint</h2>
  <h3><code>POST /roast</code></h3>
  <p><strong>Request Body (JSON):</strong></p>
  <pre><code>{
  "username": "your_tryhackme_username"
}</code></pre>

  <p><strong>Response (JSON):</strong></p>
  <pre><code>{
  "roast": "Funny roast generated by Gemini AI..."
}</code></pre>

  <hr>

  <h2>Setup Instructions</h2>
  <ol>
    <li>Clone the repository:
      <pre><code>git clone https://github.com/yourusername/roast-generator.git
cd roast-generator</code></pre>
    </li>
    <li>Create a virtual environment and install dependencies:
      <pre><code>pip install -r requirements.txt</code></pre>
    </li>
    <li>Add your <strong>Gemini API key</strong> in the code:
      <pre><code>gemini_api_key = "YOUR_API_KEY"</code></pre>
    </li>
    <li>Create a <code>roasts.txt</code> file with one roast per line.</li>
    <li>Run the Flask app:
      <pre><code>python app.py</code></pre>
    </li>
    <li>Send a POST request to <code>http://127.0.0.1:5000/roast</code>.</li>
  </ol>
